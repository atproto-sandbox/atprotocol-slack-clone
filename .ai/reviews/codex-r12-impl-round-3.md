#### R3-M1. IPC election remains split-brain prone

After a second `stale_refused`, another worker can replace the stale socket between the probe and `unlinkSync`; this worker then unlinks that newly live hub and can bind a second hub ([dm-feed-wakes.ts:973](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:973), [dm-feed-wakes.ts:984](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:984)).

Rolling old/new workers are also incompatible: the wire format changed to `snapshot_begin/chunk/end` while retaining the v1 key and unversioned socket path ([dm-feed-wakes.ts:24](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:24), [dm-feed-wakes.ts:465](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:465), [dm-feed-wakes.ts:645](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:645)). The base client ignores these frames and can unlink the current hub; the current client rejects the base `snapshot` and falls back to local state. Election needs atomic ownership plus compatible version negotiation or a coordinated all-worker drain.

#### R3-M2. Reconnection can acknowledge a wake stored only in one replica

When a pending client request is rejected during hub loss, `recordDmWake()` re-elects and then falls through to local authoritative application ([dm-feed-wakes.ts:810](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:810), [dm-feed-wakes.ts:1041](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:1041)). If another worker won and this process reconnected as a client, the mutation is not resent and broadcasting occurs only for hub mode ([dm-feed-wakes.ts:1065](/Users/mikestaub/code/peapods/bluesky/atproto-spaces/atproto-slack-clone-r12/apps/operator/src/operator/dm-feed-wakes.ts:1065)). The call succeeds while other workers miss the wake and replica state diverges. Reconnection must resend through the elected client with duplicate-safe semantics.
