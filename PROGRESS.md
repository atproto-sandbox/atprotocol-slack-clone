# Progress

## Core implementation status

- **M0 Protocol and scaffold:** pinned proposal 0016/PDS commit `787a730fcd22ed7791e2636beb509a943017ba1c`; documented protocol, operator, architecture, and operations contracts; added the separate Next.js app and generated lexicon clients. - **M2 Workspace:** added workspace/inbox provisioning, invite and acceptance discovery, public-channel setup, roster/admin views, and workspace switching.
- **M3 Messaging and sync:** added message create/edit/delete, one-level replies, per-author emoji reactions, channel history paging, encrypted cache invalidation, prompt PDS write notifications, and 60-second sync fallback.
- **M4 Private requests:** added request upsert/withdrawal, inbox writer reconciliation, generation-bound approval/denial, private-channel access, and active private rosters.
- **M5 Lifecycle:** added admin promotion/demotion, member leave/removal, privacy transitions, archive, bounded transient retries, restart recovery, periodic membership reconciliation, stalled-operation status, and the mutation pause switch.

Added two-PDS backend acceptance and real independent-app browser acceptance. Direct operator XRPC calls enforce the supported workspace envelope for mutations and inbox-writer recovery; operation lookup remains available. Channel creation and visibility changes stop when the active roster differs from live PDS membership.
